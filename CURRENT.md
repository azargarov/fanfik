# Current project state

Fanfik is a public, manually operated English-to-Russian literary translation project. This repository provides reusable translation, scene-analysis, and conservative-review prompts, a blind-assessment rubric, and a small Markdown-to-EPUB builder. It contains no book text, completed translation, or private experiment records.

The method prioritizes source fidelity, uncertainty, authorial voice, restraint, and minimal justified editing. The prompts and rubric support human-directed work; they do not automate translation acceptance or establish translation quality. Prior trials did not establish a general quality advantage for added context, adaptive editing, or model choice. Independent bilingual assessment remains an important unresolved validation need.

The EPUB builder assembles explicitly ordered UTF-8 Markdown chapter files into a basic EPUB 3 file. Its existing tests use synthetic input. It is a utility, not an end-to-end translation workflow.

**Current status:** Documentation describes the public project and its boundaries. No translation experiment or book-specific work is active. Future research candidates are listed in [BACKLOG.md](BACKLOG.md); they require an explicit task before work begins.
